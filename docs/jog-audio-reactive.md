# 음악에 반응하는 조그휠 UI

`Mixing.tsx`의 `AUDIO_REACTIVE_JOG`를 `false`로 바꾸면 기존 자동 회전 패턴으로 복원됩니다. 재생 버튼 수정이나 다른 화면에는 영향이 없습니다.

변경 전 파일은 `tmp/jog-ui-before-audio-reactive-20260916/`에 보관했습니다. 이후 수정이 있을 수 있으므로 전체 파일 덮어쓰기보다 위 설정으로 복원하는 것을 권장합니다.

최종 출력의 분석 전용 분기에서 음량과 저음(40–250Hz), 중음(250–2000Hz), 고음(2000–10000Hz)을 읽습니다. EQ와 스크래치 소리도 반영되며, 분석 분기는 스피커로 연결하지 않습니다.

기존 파란 도트 두 덩어리를 유지하면서 저음은 팽창, 중음은 폭, 고음은 물결, 음량은 밝기와 회전 속도에 반영합니다. 값은 빠르게 상승하고 천천히 내려오며 일시정지 시 반응이 가라앉습니다. 동작 줄이기 설정에서는 정적인 기존 패턴을 표시합니다.

슬라이더는 시각적 회전 배율(0.4–1.6)을 직접 조절하며 실제 음원 속도(0.9–1.1배)는 그대로입니다. Low 노브는 패턴 간격과 팽창, Mid는 패턴 폭, High는 물결과 바깥 링을 직접 조절합니다. 음악 분석 반응을 추가로 합성합니다. 노브 입력은 재생을 멈춘 상태에서도 모양에 반영됩니다.
